# 트립날씨 네이버 블로그 작성 규칙

2026-11-03 기준 · SK

## 1. 운영 방식

- 매일 아침 7시 43분(한국 시각)에 글 2개를 씁니다. 글 1은 요일 주제, 글 2는 키워드 목록의 다음 키워드예요.
- 결과는 [복사 페이지](https://claude.ai/artifact/C8fyBfg4bY1rUx3dPzrQLc) 하나에 올립니다. 오늘 글과 어제 글이 함께 실려요.
- 페이지에서 "제목 복사", "본문 복사" 버튼으로 복사하고, 그림은 "그림 저장" 버튼으로 받아 네이버 에디터에 올립니다.
- 스레드 답글은 두 제목과 페이지 링크 한 줄만 보냅니다. 그림은 첨부하지 않아요(스레드 첨부 한도).
- 2주 시험 뒤 2026-11-06에 GA4의 네이버 블로그 유입을 보고 계속할지 정합니다.

## 2. 주제와 키워드 고르기

글 1은 요일별 주제로 씁니다. 모두 언제 읽어도 쓸모 있는 기준·방법·월 단위 가이드예요.

| 요일 | 주제 |
| --- | --- |
| 월 | 낚시: 바람·파고·물때 보는 법, 출조 포기 기준 |
| 화 | 등산: 정상 체감온도, 산행 포기 기준, 명산별 좋은 달 |
| 수 | 해외: 도시별 가기 좋은 달, 우기·건기 (구매 가이드형) |
| 목 | 캠핑: 밤 기온별 장비, 바람·타프 기준 (구매 가이드형) |
| 금 | 예보 읽는 법: 강수확률·강수량, 세 모델 차이 |
| 토 | 장소 가이드: 인기 장소의 좋은 때와 날씨 특징 |
| 일 | 계절 가이드: 다가오는 달의 레저 날씨 |

글 2는 SK가 뽑은 네이버 검색량 목록의 '블로그 키워드 순서'에서 아직 안 쓴 다음 키워드로 씁니다. 쓴 키워드에는 날짜를 표시하고, 두 글의 키워드가 겹치지 않게 해요. 큰 말("다낭 여행")보다 장소+월/레저+날씨 같은 롱테일을 고르고, 같은 틀로 시리즈를 쌓아 주제를 '여행·레저 날씨' 하나로 모읍니다.

## 3. 검색 노출

- 글마다 핵심 키워드 하나. 제목 맨 앞에 그대로 두고, 뒤에 숫자 훅을 붙여 25~30자로 씁니다.
- 같은 키워드를 첫 문장과 첫 해시태그에 넣고, 본문에는 자연스럽게 3~5번 씁니다. 소제목 하나 이상에 키워드 변형을 넣어요.
- 억지 반복은 하지 않습니다.
- tripnalc 링크는 글 하나에 3개 이하(캡처 아래 1~2개, 끝 1개).
- 출처는 링크 없이 글자로만 적습니다.
- 해시태그는 8~10개, 첫 번째는 핵심 키워드.

## 4. 글 형식과 순서

본문은 1,500자 안팎, 문장은 짧게 씁니다. 순서는 아래와 같아요.

1. 대가성 문구: "※ 글 속 상품 링크로 구매하면 작은 수수료를 받을 수 있어요 (네이버 쇼핑 커넥트)"
2. 도입 1~2문장 (첫 문장에 키워드)
3. "📌 3줄 요약"과 ✓ 세 줄 (네이버 인용구로 넣기)
4. 표지 카드 그림
5. 굵은 소제목 01~04, 섹션마다 3~6문장과 그림(캡처나 카드) 하나
6. 비교표 그림 1개
7. 출처 [1] [2]
8. "이런 글도 있어요" (관련 글·페이지 2~3개)
9. 해시태그

제목은 숫자와 사람들이 검색하는 질문 모양으로 씁니다(예: "~는 몇 도일까?"). 날짜는 넣지 않아요.

## 5. 줄바꿈·표기·링크

- 물음표로 끝나는 문장 다음은 새 줄에 씁니다.
- "이런 글도 있어요"는 한 줄에 글 하나씩.
- 문단 사이, 소제목과 본문 사이는 빈 줄 하나. 마침표로 끝나는 설명 문장은 한 문단에 이어 씁니다.
- 본문에 "제목:", "결론부터." 같은 안내 말을 쓰지 않습니다. 제목은 제목 칸에만 넣어요.
- 소제목은 #이 아닌 굵은 글씨로 씁니다.
- tripnalc.com은 늘 https:// 로 시작하는 전체 주소로 써서 링크가 걸리게 합니다.

## 6. 그림

- 표지 카드: 1080×1350 진녹 카드(큰 숫자, ✓ 3줄, tripnalc.com). Claude가 만들어 복사 페이지에 올립니다.
- 표: 네이버에 표를 옮길 수 없어서 늘 그림으로 만듭니다. 본문에는 "[표 이미지: 파일명]" 자리만 둡니다.
- 캡처: "[캡처: 장소]" 줄 아래에 "👉 https://tripnalc.com/..." 링크 한 줄. SK가 사이트를 캡처해 넣고, 링크는 사이트로 오는 통로라 그대로 둡니다.
- 그림은 직접 만든 카드와 트립날씨 캡처만 씁니다. 다른 곳 그림은 쓰지 않아요.

## 7. 쇼핑 커넥트

- 글마다 상품 자리 1~2개: "[쇼핑 커넥트: 상품 종류 + 고르는 기준]" 아래에 "(쇼핑 커넥트 링크)". 링크는 SK가 직접 만듭니다.
- 상품 자리는 해당 섹션 끝이나 "이런 글도 있어요" 앞에 둡니다.
- 수(해외)·목(캠핑)은 구매 가이드형: 날씨 고민 공감 → 날씨 숫자로 고르는 기준 → 단점부터 인정한 상품 → 맞는 사람·안 맞는 사람 → 링크(중간 1번, 끝 1번).
- 상품은 SK가 products.md에 적어 둔 것에서 고릅니다. 없으면 상품 종류만 적어요.
- 주 1~2번은 수수료 높은 상품군(건강기능식품·이너뷰티·뷰티·생활가전)을 날씨와 엮습니다. 예: 건조한 달 → 보습, 일조 짧은 겨울 → 비타민D, 산행 뒤 → 관절 영양제.
- 건강기능식품은 제품에 표시된 기능성 문구 안에서만 쓰고, 질병 예방·치료 표현은 쓰지 않습니다(식약처).

## 8. 금지 사항

- 하루만 지나도 쓸모없는 글: "이번 주말", 특정 날짜, 그날 예보 숫자로 결론 내기.
- 지어낸 숫자, 브랜드, 가격, 쿠폰, 한정 수량.
- 써 보지 않은 제품을 써 본 척("3주간 써봤다", 내돈내산).
- 상세페이지 캡처 도배, 다른 곳 그림.
- 마크다운 표(| |), "제목:"·"결론부터." 같은 안내 말.
- 땡처리·항공권·패키지 키워드(여행사 광고 경쟁).
